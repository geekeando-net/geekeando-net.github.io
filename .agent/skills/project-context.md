# Contexto de Proyecto: Geekeando Lab

Este repositorio es el laboratorio de Robótica Educativa y tecnología Maker.

## Reglas de Implementación (Obligatorias)
* **Estructura de Contenido**: Seguir estrictamente el modelo **Page Bundle** (carpeta propia con index.md, cover.png, downloads/ y gallery/).
* **Gestión de Medios**: 
    - Referenciar autores desde `src/assets/images/authors/`.
    - Usar `@authors/nombre-archivo.jpg` en el MD.
* **Generación de Posts**: Utilizar siempre el snippet `geekproject` para mantener la consistencia del Frontmatter.
* **Tono**: Pedagógico y entusiasta, optimizado para contextos de bajos recursos y robótica low-cost.
